## 🧭 System Overview

**Ophanim Lithic Chess** is a single-file, WebGL-powered 3D/2D tactical chess application designed around the sacred geometry, isopsephic mechanics, and polar vector mathematics of the **Ophanim Engine Framework**. 

Rather than standard Staunton chess pieces, every unit on the board is a physical representation of topological solids, integer volumes, and universal mathematical constants.

## ✨ Key Features & Functionality

### 1. Dual View Engine (3D WebGL / 2D Tactical)
* **3D Perspective:** Built with Three.js using procedural geometry, custom lighting, internal point-light emission, and smooth camera OrbitControls.
* **2D Perspective:** Minimalist geometric vector board for fast tactical calculation.

### 2. Gameplay Modes
* **Visitor vs. Computer:** Integrated lightweight AI with move validation, check/checkmate detection, and turn delay logic powered by `chess.js`.
* **Visitor vs. Visitor:** Local pass-and-play 2-player mode.

### 3. Classic Games Interactive Library
Includes interactive PGN move replay controls (Start, Back, Next, End, Autoplay speeds, move list scrubber, and key annotation markers) for historical masterworks:
1. **Byrne vs. Fischer (1956)** — *The Game of the Century*
2. **Kasparov vs. Topalov (1999)** — *Kasparov's Immortal*
3. **Fischer vs. Spassky (1972)** — *World Championship Game 6*
4. **Anderssen vs. Kieseritzky (1851)** — *The Immortal Game*
5. **Aronian vs. Carlsen (2012)** — *Bilbao Masters Round 1*
* **Custom PGN Importer:** Allows players to paste and replay any custom PGN string.

### 4. "Become a Stone" Lithic Membership Tier
* **Lithos Node Sign-In:** Allows visitors to set a custom handle and receive a verified "Stone" status badge stored locally.
* **Live Chat & Commentary Panel:** Unlocks a side-drawer chat console for posting local tactics and notes.
* **Lithos Library Portal:** Direct download links for research whitepapers (*The Lithos Manifesto*, *Ophanim Specification*, *Philosophy From A Stone*).
* **Crypto Tip Jar:** Integrated crypto modal supporting BTC, ETH, SOL, and ADA wallet addresses.

### 5. Ambient Sound & Audio Engine
* **Web Audio API Synthesizer:** Generates harmonic 432 Hz tonal chimes upon piece selection, moves, and checkmate states.
* **SomaFM Drone Zone Audio Stream:** HTTPS-secured ambient music stream player with external fallback links.

## 🚀 Quick Start / Deployment

### Running Locally
1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser. No build step or local server required!

### One-Click Deployment on Vercel
1. Push this repository to **GitHub** (Public or Private).
2. Log into **Vercel** and click **Add New... → Project**.
3. Select your repository and click **Deploy**.
4. Your site will be live on an HTTPS domain within 15 seconds!
