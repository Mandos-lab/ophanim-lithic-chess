Every entry is added up letter by letter, so you can check it yourself. Standard letter values, 27 signs: α 1 to ω 800, with final ς counted as 200.

Count a word, or search a number

Accents and breathing marks are ignored. A number shows the index entries with that value, and can search the Strong’s Greek lexicon.

About this index

Each value is computed by this page from the Greek letters, not typed in by hand, and a green mark means the page’s total matches the value in the source. The entries so far come from the “Alphanumeric Handshake” summary. Their authorship is still to be confirmed, so no entry is marked as anyone’s finding.

The lexicon search uses Strong’s Greek dictionary (public domain) and the same plain letter values. It lists words that share a number. That is a fact about the letters, not a claim that the words are related.
